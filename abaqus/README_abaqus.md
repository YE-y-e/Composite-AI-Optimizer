# ABAQUS 离线验证算例说明

本目录包含用于交叉验证本系统 Ritz 求解精度的三个典型工况的 ABAQUS 模型与结果文件，供评审专家独立复核。

## 1. 软件版本与单位制
- **软件版本**：ABAQUS 2024 / Standard
- **单位制**：SI (mm, N, MPa)
- **板尺寸**：500 mm × 500 mm 正方形板
- **材料体系**：T300/5208（E1=181000 MPa, E2=10300 MPa, G12=7170 MPa, ν12=0.28）
- **边界条件**：四边简支 (SS1)

## 2. 算例对应关系与一阶特征值
| Job 名称 | 对应场景 | 铺层序列 | 载荷工况 (Nx / Ny) | 一阶特征值 | 换算临界载荷 Ncr |
| :--- | :--- | :--- | :--- | :--- | :--- |
| Job_1_Drone | 无人机机翼蒙皮 | [-44.9/44.9/45.2/-45.2]s | 500 / 500 N/m | 2.1118 | 2111.8 N/m |
| Job_2_Battery | 新能源电池包 | [44.96/-45.28/-44.64/-90]s | 1000 / 200 N/m | 1.9976 | 1997.6 N/m |
| Job_3_Solar | 航天器太阳能帆板 | [-45/45/45/-45]s | 1500 / 800 N/m | 6.5138 | 6513.8 N/m |

*(注：模型采用 mm 与 N 单位制，施加的单位基准载荷为 -1 N/mm 及其比例。)*

## 3. 复现步骤
1. 打开 ABAQUS/CAE。
2. 通过 `File -> Import -> Model` 导入对应的 `.inp` 文件（即可完整还原材料、网格、边界与载荷）。
3. 创建 Job 并提交计算（或直接查看提供的 `.odb` 结果文件）。
4. 点击 `Results`，在 `Step/Frame` 中查看 `Mode 1` 的 `EigenValue`，即可复现上表数据。
